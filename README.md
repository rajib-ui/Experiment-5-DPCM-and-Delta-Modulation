Experiment 5 — DPCM & Delta Modulation

This experiment demonstrates the working of Differential Pulse Code Modulation (DPCM) and Delta Modulation (DM). It studies prediction and quantization errors, the effect of step size, and distortions such as granular noise and slope-overload distortion.
